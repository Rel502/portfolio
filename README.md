
# Michael Zeitler – Developer Portfolio

A personal developer portfolio showcasing my skills, projects, and experience in frontend web development.

The website was built using HTML, CSS, and Vanilla JavaScript, with a focus on responsive design, clean code, accessibility, and an intuitive user experience.

Developed as part of the web development bootcamp at Developer Akademie.

## Features

- **Responsive Design** – Optimized layouts for desktop, tablet, and mobile devices.
- **Multilingual Support** – Switch between English and German, with language preferences saved locally.
- **Interactive Navigation** – Responsive navigation menu with active section highlighting.
- **Project Showcase** – Explore selected development projects with descriptions, technologies, live demos, and GitHub links.
- **Scroll Animations** – Smooth visual transitions and animations triggered while scrolling.
- **Interactive Hero Section** – Animated profile image with hover effects.
- **Contact Form** – Form validation and message submission through a PHP backend.
- **Accessibility** – Semantic HTML, descriptive labels, and accessibility attributes.
- **Legal Information** – Dedicated pages for the legal notice and privacy policy.

## Tech Stack

- **HTML5** – Semantic structure and page content
- **CSS3** – Styling, animations, and responsive layouts
- **JavaScript (Vanilla JS)** – Interactive functionality and application logic
- **PHP** – Server-side processing of contact form submissions
- **JSON** – Translation files for multilingual content
- **Git & GitHub** – Version control and project management

## Getting Started

To run the portfolio locally, follow these steps:

### 1. Clone the repository

```bash
git clone https://github.com/Rel502/portfolio.git
```

### 2. Open the project directory

```bash
cd portfolio
```

### 3. Start the application

Open the project in Visual Studio Code and launch `index.html` using the **Live Server** extension.

No additional frontend dependencies or build process are required.

**Note:** The contact form sends requests to an external PHP endpoint hosted on the production server. The frontend can be viewed locally, but processing contact form submissions requires the configured backend to be available and accept the requests.
